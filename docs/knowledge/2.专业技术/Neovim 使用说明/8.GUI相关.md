这一篇只记录偏界面层的能力，包括鼠标、剪贴板和 Select 模式。它们不是学习 Neovim 的第一优先级，但在桌面环境里经常会遇到。

## 鼠标相关选项

常见选项包括：

1. `mouse`：控制哪些模式允许鼠标。
2. `mousemodel`：控制鼠标点击的行为。
3. `mousetime`：控制双击识别时间。
4. `mousehide`：输入时是否隐藏鼠标。
5. `selectmode`：鼠标选中时进入 Visual 还是 Select 模式。

例如，想在常见模式下都启用鼠标：

```vim
:set mouse=a
```

## 剪贴板

不同平台对系统剪贴板的支持方式不完全一样，但常见用法是通过寄存器 `*` 或 `+`：

1. `"*y` 或 `"+y`：复制到系统剪贴板。
2. `"*p` 或 `"+p`：从系统剪贴板粘贴。

如果发现命令无效，优先检查当前 Neovim 是否带剪贴板支持，以及当前终端或 GUI 前端是否正确接入系统剪贴板。

## Select 模式

Select 模式和 Visual 模式很像，区别在于：

1. Visual 模式更像“选中一段后再执行命令”。
2. Select 模式更像传统编辑器，输入文字时会直接替换选区内容。

有些 GUI 或鼠标交互下会更容易触发 Select 模式，但实际日常编辑中，大多数人还是更常用 Visual 模式。

## 使用建议

1. 如果你主要在终端里工作，优先掌握 Normal/Insert/Visual 的键盘操作，不要过早依赖鼠标。
2. 如果你很依赖系统剪贴板，建议先确认 `"+` 和 `"*` 在当前环境中的实际行为。
3. 这部分更偏环境适配，遇到问题时优先查帮助文档而不是机械照搬别人的配置。---
