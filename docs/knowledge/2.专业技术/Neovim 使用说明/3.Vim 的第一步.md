这一篇只覆盖最基本的起步动作：打开文件、进入插入模式、删改文本、撤销重做，以及如何退出与查看帮助。

## 打开文件

### 在终端中打开

```bash
nvim path/to/file
```

如果文件存在，会直接打开内容；如果文件不存在，Neovim 会新建一个缓冲区，并提示这是一个新文件。

### 在 Neovim 内部打开

```vim
:edit path/to/file
```

这和在外部执行 `nvim path/to/file` 的效果本质一样，只是入口不同。

## 两个最重要的模式

Neovim 是模态编辑器，入门时至少先分清两种模式：

1. Normal 模式：按键主要表示命令。
2. Insert 模式：按键主要表示输入文本。

启动后默认是 Normal 模式。

### 进入插入模式

```text
i
```

进入后左下通常会显示 `-- INSERT --`。

### 回到 Normal 模式

```text
Esc
```

如果左下没有模式提示，可以手动开启：

```vim
:set showmode
```

## 最基础的移动

在 Normal 模式下可以先记住下面四个键：

1. `h`：向左
2. `j`：向下
3. `k`：向上
4. `l`：向右

方向键也能用，但如果准备长期使用 Vim 体系，尽早适应 `hjkl` 会更高效。

## 最基础的编辑

### 删除字符和整行

1. `x`：删除当前光标所在字符。
2. `dd`：删除当前行。
3. `J`：把下一行拼接到当前行末尾。

### 追加与新建行

1. `a`：在光标后进入插入模式。
2. `o`：在当前行下方新开一行，并进入插入模式。
3. `O`：在当前行上方新开一行，并进入插入模式。

## 撤销和重做

1. `u`：撤销上一次修改。
2. `CTRL-R`：重做。

这组命令并不只针对删除操作，只要是修改都可以撤销和重做。

## 退出与保存

1. `ZZ`：保存并退出当前文件。
2. `:q!`：不保存，强制退出。
3. `:e!`：放弃当前修改，重新加载文件。

## 查看帮助

1. `:help` 或 `:h`：打开帮助。
2. `F1`：很多环境下也可以直接打开帮助。
3. `:help x`：查看某个命令说明。
4. `:help deleting`：按主题查看帮助。

常见查询方式如下：

| 查询内容 | 查询方式 |
| --- | --- |
| 查询一个主题 | `:help {subject}` |
| 查询一个命令 | `:help x` |
| 查询 Normal 模式快捷键 | `:help CTRL-A` |
| 查询 Insert 模式快捷键 | `:help i_CTRL-A` |
| 查询配置项 | `:help 'number'` |
| 查询错误码 | `:help E37` |

## 两个容易混淆的点

1. 单键命令不是“快捷键”，而是这个编辑模型本身的一部分。
2. 冒号命令也是命令系统的一部分，只是输入方式不同，不是额外附加层。
