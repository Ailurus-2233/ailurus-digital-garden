本文记录在 Linux 环境下安装 Docker 的最小流程，当前以 Arch Linux 为例。

## 安装步骤

### 1. 安装 Docker

```bash
sudo pacman -S docker
```

### 2. 启动 Docker 服务

```bash
sudo systemctl start docker.service
```

### 3. 设置开机启动

```bash
sudo systemctl enable docker.service
```

### 4. 把当前用户加入 docker 组

```bash
sudo gpasswd -a $USER docker
```

### 5. 按需处理镜像拉取网络问题

宿主机文件路径：/etc/docker/daemon.json

公共镜像加速源的可用性变化很快，很多历史文章里的地址已经失效，所以不建议直接复制一串未知来源的加速地址。更稳妥的做法通常有三种：

1. 使用公司或云厂商提供的私有镜像仓库与加速服务。
2. 通过代理工具解决对 Docker Hub 的访问问题。
3. 仅在已经确认可用的情况下，手动配置单个镜像加速地址。

如果你已经有明确可用的加速地址，可以按下面的模板配置：

```json
{
  "registry-mirrors": [
    "https://your-registry-mirror.example.com"
  ]
}
```

如果没有稳定来源，宁可先不配，也不要堆一组来源不明、时效不可控的公共地址。

### 6. 重启系统或 Docker 服务

```bash
reboot
```

### 7. 验证安装结果

```bash
docker info
docker compose version
```

## 使用建议

1. 新用户执行过第 4 步后，重新登录一次 shell，避免组权限没有生效。
2. 如果只想重载配置，也可以执行 `sudo systemctl restart docker`，不一定必须整机重启。
3. 如果当前 shell 还没有识别新的组权限，可以先尝试执行 `newgrp docker`。
