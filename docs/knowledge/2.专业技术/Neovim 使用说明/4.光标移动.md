这一篇把常见移动动作整理成几组：词级移动、行内移动、屏幕滚动、搜索跳转和标记跳转。

## 单词级移动

1. `w`：移动到下一个单词开头。
2. `b`：移动到上一个单词开头。
3. `e`：移动到下一个单词结尾。
4. `ge`：移动到上一个单词结尾。

如果想查更完整的词与文本对象列表，可以继续看 [12.快捷键索引-文本对象](./12.快捷键索引-文本对象.md)。

## 行内移动

1. `$`：移动到当前行末尾。
2. `0`：移动到当前行第一个字符。
3. `^`：移动到当前行第一个非空白字符。
4. `f<char>`：向右找第一个指定字符。
5. `F<char>`：向左找第一个指定字符。
6. `t<char>`：移动到目标字符前一位。
7. `T<char>`：移动到目标字符后一位。

执行过一次 `f/F/t/T` 后：

1. `;`：重复同方向查找。
2. `,`：按相反方向重复查找。

## 括号与结构跳转

1. `%`：当光标在括号附近时，跳到对应括号。
2. `gg`：跳到文件开头。
3. `G`：跳到文件末尾。
4. `<number>G`：跳到指定行。
5. `<number>gg`：同样可跳到指定行。
6. `<number>%`：跳到文件大约第 n% 的位置。

## 屏幕位置相关移动

1. `H`：跳到当前屏幕顶部附近。
2. `M`：跳到当前屏幕中间附近。
3. `L`：跳到当前屏幕底部附近。

这里的 H/M/L 说的是当前窗口可见区域，不是整个文件的开头、中间和结尾。

## 滚动

1. `CTRL-U`：向上滚动半屏。
2. `CTRL-D`：向下滚动半屏。
3. `CTRL-B`：向上翻一整屏。
4. `CTRL-F`：向下翻一整屏。
5. `CTRL-Y`：窗口向上滚动一行。
6. `CTRL-E`：窗口向下滚动一行。
7. `zt`：把当前行滚到窗口顶部。
8. `zb`：把当前行滚到窗口底部。

## 搜索

1. `/<word>`：向后搜索。
2. `?<word>`：向前搜索。
3. `n`：跳到下一个结果。
4. `N`：跳到上一个结果。
5. `*`：向后搜索当前光标所在完整单词。
6. `#`：向前搜索当前光标所在完整单词。

常见辅助选项：

```vim
:set ignorecase
:set hlsearch
:set incsearch
:set wrapscan
```

如果只想临时清掉高亮：

```vim
:nohlsearch
```

## 简单正则

1. `/^word`：匹配行首。
2. `/word$`：匹配行尾。
3. `/a.c`：`.` 匹配任意单个字符。

更完整的搜索模式可以看 [13.快捷键索引-正则搜索](./13.快捷键索引-正则搜索.md)。

## 跳回之前的位置

1. `` `` ``：回到上一次跳转前的位置。
2. `CTRL-O`：回到更早的位置。
3. `CTRL-I`：回到更新的位置。
4. `:jumps`：查看跳转历史。

## 标记位置

1. `m<char>`：设置局部标记。
2. `` `<char> ``：跳到局部标记。
3. `m<char>` 中如果 `<char>` 是大写字母，则标记可以跨文件使用。
4. `:marks`：查看当前标记列表。

## 使用建议

1. 真正常用的是“操作命令 + 移动命令”的组合，而不是单独记住某一个动作。
2. 如果发现自己频繁用方向键或鼠标移动，通常说明可以多练几组词级和行级移动。---
