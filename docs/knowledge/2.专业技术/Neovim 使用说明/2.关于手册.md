Neovim 的学习入口最好不是网上零散文章，而是内置帮助文档本身。因为很多细节行为、命令语义和边界情况，最终都以帮助文档为准。

## 帮助文档分成两类

1. User Manual：偏任务导向，更适合从头到尾阅读，像一本循序渐进的教材。
2. Reference Manual：偏精确查询，适合已经知道关键词后按需翻阅。

这两部分配合起来用，效率会比只靠搜索引擎高很多。

## 学会来回跳转

帮助文档内部有大量可跳转的标签，例如 `|bars|`、`|help.txt|`、`'number'`、`":write"` 这类主题。

常用跳转方式如下：

1. `CTRL-]`：跳转到光标下的帮助主题。
2. `CTRL-O`：跳回上一个位置。
3. `CTRL-T`：从标签栈返回，和 `CTRL-]` 配合时很常用。

如果你打算长期使用 Neovim，这组跳转能力比单独记很多命令更重要。

## 创建配置文件

在命令行模式中可以直接执行下面这组命令来创建最基本的配置文件：

```vim
:call mkdir(stdpath('config'), 'p')
:exe 'edit' stdpath('config') . '/init.vim'
:write
```

常见配置目录位置如下：

1. Windows：`~/AppData/Local/nvim/`
2. Linux / macOS：`~/.config/nvim/`

当然，也可以直接去对应目录手动创建 `init.vim`。

## 这几个命令在做什么

1. `stdpath('config')`：获取当前系统下 Neovim 的标准配置目录。
2. `mkdir(..., 'p')`：递归创建目录。
3. `:edit`：打开指定文件。
4. `:write`：保存当前文件。

如果后面改成使用 Lua 配置，那么入口文件通常会变成 `init.lua`，但目录位置仍然是同一套。

## 内置教程

如果希望边操作边学习，可以直接执行：

```vim
:Tutor
```

它会打开一个内置教程，比只看文档更适合第一次接触模式编辑的人。
