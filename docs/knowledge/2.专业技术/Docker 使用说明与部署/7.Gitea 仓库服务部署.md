## 1. 持久化目录

```bash
mkdir -p ~/docker/gitea
```

## 2. compose 示例

```yaml
services:
  gitea:
    image: gitea/gitea:1.24.6
    container_name: gitea
    environment:
      - USER_UID=1000
      - USER_GID=1000
    restart: always
    volumes:
      - ~/docker/gitea:/data
      - /etc/localtime:/etc/localtime:ro
    ports:
      - "3000:3000"
      - "2222:22"
```

## 3. 端口说明

1. 3000 用于 Web 管理界面。
2. 2222 对应容器内的 22，用于 Git over SSH。

把宿主机 22 直接映射给容器虽然也能工作，但很容易和宿主机自己的 SSH 服务冲突，因此更推荐用 2222 之类的独立端口。

## 4. 启动容器

```bash
docker compose up -d
```

## 5. 初始化配置

1. 访问 `http://host:3000` 进入初始化向导。
2. 最小部署场景可以先使用内置 SQLite，长期运行更推荐 PostgreSQL 或 MySQL。
3. 如果启用了 SSH 推送，记得把访问地址改成宿主机的 2222 端口。
4. 初始化完成后创建管理员账户，并确认 `ROOT_URL`、SSH 地址和仓库存储路径设置正确。

## 6. 使用建议

1. 如果准备反向代理到域名访问，建议把外部访问地址和克隆地址一起核对。
2. 数据目录需要单独备份，相关说明见 [11.备份与恢复策略](./11.备份与恢复策略.md)。
3. 如果仓库目录无法写入，优先检查容器 UID/GID 与宿主机目录权限，相关说明见 [10.持久化文件权限问题](./10.持久化文件权限问题.md)。
