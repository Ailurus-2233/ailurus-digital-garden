Linux 的权限管理核心其实就四件事：

1. 看当前属主和属组是谁。
2. 改读写执行权限。
3. 改属主和属组。
4. 理解默认权限是怎么来的。

## 1. chmod

```bash
chmod [选项] 模式 文件
```

常见选项：

1. `-R`：递归修改目录下所有文件。
2. `-f`：忽略不存在的文件或部分错误。
3. `-v`：显示变更结果。

常见模式元素：

1. `u`：用户权限。
2. `g`：组权限。
3. `o`：其他用户权限。
4. `a`：所有用户。
5. `r`：读。
6. `w`：写。
7. `x`：执行。
8. `+`：增加权限。
9. `-`：移除权限。
10. `=`：直接覆盖设置。

示例：

```bash
chmod u+x file
chmod u=rw file
chmod g-w file
chmod a+x file
chmod -x file
chmod -R u+rwX dir
```

## 2. chown

```bash
chown [选项] 用户:组 文件
```

常见选项：

1. `-R`：递归修改。
2. `-f`：忽略部分错误。
3. `-v`：显示变更结果。

示例：

```bash
chown root:root file
chown -R root:root dir
chown deploy:www-data app.log
```

## 3. chgrp

```bash
chgrp [选项] 组 文件
```

示例：

```bash
chgrp root file
chgrp -R root dir
```

如果你本来就准备同时改属主和属组，通常直接用 `chown user:group` 更直接。

## 4. umask

```bash
umask [模式]
```

`umask` 不是“直接设置文件权限”，而是“定义新建文件和目录时默认要屏蔽哪些权限”。

例如：

```bash
umask 022
```

常见效果是：

1. 新建文件通常变成 `644`
2. 新建目录通常变成 `755`

## 5. 使用建议

1. 先用 `ls -l` 看清当前属主、属组和权限，再决定改什么。
2. 尽量避免对系统目录直接递归 `777`。
3. 如果权限问题和服务运行有关，通常还要结合用户身份和 systemd 服务一起排查，相关内容可继续看 [4.用户指令](./4.用户指令.md) 和 [5.systemctl 使用实例](./5.systemctl%20使用实例.md)。
