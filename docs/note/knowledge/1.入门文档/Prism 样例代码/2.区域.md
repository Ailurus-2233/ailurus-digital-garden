定义一个 Region：

```xml
xmlns:prism="http://prismlibrary.com/"
<ContentControl prism:RegionManager.RegionName="ContentRegion" />
```

在任意控件中通过附加属性 `RegionManager.RegionName` 给指定 `ContentControl` 添加一个 `RegionName`，用于后端绑定特定的控件。
