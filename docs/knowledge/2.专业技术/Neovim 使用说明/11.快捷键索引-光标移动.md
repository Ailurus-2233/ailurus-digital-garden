## 左右移动

| 指令 | 是否支持计数 | 常见按键形式 | 说明 |
| --- | --- | --- | --- |
| `h` | 是 | `h` `CTRL-H` `<BS>` `<Left>` | 向左移动 |
| `l` | 是 | `l` `<Space>` `<Right>` | 向右移动 |
| `0` | 否 | `0` `<Home>` | 到行首 |
| `^` | 否 | `^` | 到第一个非空白字符 |
| `$` | 是 | `$` `<End>` | 到行尾 |
| `g0` | 否 | `g0` | 到屏幕行行首 |
| `g^` | 否 | `g^` | 到屏幕行第一个非空白字符 |
| `g$` | 是 | `g$` | 到屏幕行行尾 |
| `gm` | 否 | `gm` | 到屏幕行中间 |
| `gM` | 否 | `gM` | 到整行中间 |
| `|` | 是 | `|` | 到第 n 列 |
| `f{char}` | 是 | `f` | 向右找第 n 个字符 |
| `F{char}` | 是 | `F` | 向左找第 n 个字符 |
| `t{char}` | 是 | `t` | 到右侧目标字符前一位 |
| `T{char}` | 是 | `T` | 到左侧目标字符后一位 |
| `;` | 是 | `;` | 重复上次 `t/T/f/F` |
| `,` | 是 | `,` | 反向重复上次 `t/T/f/F` |

## 上下移动

| 指令 | 是否支持计数 | 常见按键形式 | 说明 |
| --- | --- | --- | --- |
| `k` | 是 | `k` `CTRL-P` `<Up>` | 向上 |
| `j` | 是 | `j` `CTRL-J` `CTRL-N` `<Down>` | 向下 |
| `-` | 是 | `-` | 到上一行第一个非空白字符 |
| `+` | 是 | `+` `CTRL-M` `<CR>` | 到下一行第一个非空白字符 |
| `_` | 是 | `_` | 到第 n-1 行第一个非空白字符 |
| `G` | 是 | `G` | 到第 n 行，默认文件末尾 |
| `gg` | 是 | `gg` | 到第 n 行，默认文件开头 |
| `%` | 是 | `%` | 到文件大约第 n% 的位置 |
| `gk` | 是 | `gk` | 按屏幕行向上 |
| `gj` | 是 | `gj` | 按屏幕行向下 |
