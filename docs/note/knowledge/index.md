## 说明

欢迎来到我的个人知识库，这里记录了我在学习和工作中积累的各种知识和经验。内容涵盖编程、软件开发、项目管理等多个领域，希望能对你有所帮助。

区别于[博客](/blog/)，这里的内容更注重单元化的知识积累和整理，每一篇文章都力求简洁明了，便于快速查阅和学习。

如果你对某个主题感兴趣，欢迎深入阅读相关的文章和笔记。你也可以通过搜索功能快速找到你需要的信息。

如果你有任何建议或意见，欢迎通过[关于我](/about/)与我交流。你的反馈将帮助我不断改进和完善这个知识库。

## 知识库分类依据

- [入门文档](/knowledge/document/)：整理某技术的入门方案，通常是技术官方文档中或入门的内容整理通用的技术点整理
- [专业技术](/knowledge/expertise/)：在开发过程中，通用技术点整理或者某领域特化的技术点整理
- [学习笔记](/knowledge/study/)：面向书本的学习笔记
- [问题记录](/knowledge/problem/)：常见问题的记录和解决方法
- [其他归纳](/knowledge/other/)：其他不适合上述分类的内容
