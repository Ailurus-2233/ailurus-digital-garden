Neovim 的窗口管理能力很强，但前提是先分清楚：窗口只是同一会话里的视图组织方式，不等于文件本身，也不等于标签页。

## 基本分屏

1. `:split`：水平分屏。
2. `:vsplit`：垂直分屏。
3. `:new`：打开空白新窗口。
4. `:split path/to/file`：在新窗口中打开指定文件。
5. `:close`：关闭当前窗口。
6. `:only`：只保留当前窗口。

## 在窗口间移动光标

1. `CTRL-W w`：在窗口之间循环切换。
2. `CTRL-W h`：到左侧窗口。
3. `CTRL-W j`：到下方窗口。
4. `CTRL-W k`：到上方窗口。
5. `CTRL-W l`：到右侧窗口。
6. `CTRL-W t`：到最上方窗口。
7. `CTRL-W b`：到最下方窗口。

## 调整窗口大小

1. `CTRL-W +`：增加高度。
2. `CTRL-W -`：减小高度。
3. `<number>CTRL-W +`：一次调整多行。
4. `:3split`：按指定高度分屏。

## 移动窗口位置

1. `CTRL-W H`：把当前窗口移到最左侧。
2. `CTRL-W L`：把当前窗口移到最右侧。
3. `CTRL-W J`：把当前窗口移到最下侧。
4. `CTRL-W K`：把当前窗口移到最上侧。

## 同时打开多个文件并分屏

```bash
nvim -o test1.txt test2.txt test3.txt
nvim -O test1.txt test2.txt test3.txt
```

1. `-o`：水平分屏。
2. `-O`：垂直分屏。

## 差异模式

```bash
nvim -d test.txt~ test.txt
```

这适合用来对比备份文件和当前文件。常见命令包括：

1. `]c`：跳到下一个差异。
2. `[c`：跳到上一个差异。
3. `zo`：展开折叠。
4. `zc`：关闭折叠。
5. `dp`：删除当前差异块。
6. `do`：把另一侧差异应用过来。

## 标签页

如果不希望大量分屏挤占可视区域，可以使用标签页：

```vim
:tabedit filename
```

常见动作：

1. `gt`：切到下一个标签页。
2. `gT`：切到上一个标签页。
3. `:tabonly`：只保留当前标签页。

## 使用建议

1. 多窗口适合同时看多份内容；多文件适合在不同文件间切换；标签页适合把任务分组。
2. 一旦窗口过多，先考虑是否应该切回标签页，而不是继续分屏。
3. 如果只是短暂查看差异，优先用差异模式，不要手工左右对照。---
