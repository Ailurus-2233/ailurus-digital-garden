当编辑不再只围绕一个文件时，Neovim 的参数列表、文件跳转、寄存器和备份选项就会开始变得实用。

## 打开多个文件

```bash
nvim one.c two.c three.c
```

在多个文件之间可以使用参数列表切换：

1. `:next`：下一个文件。
2. `:previous`：上一个文件。
3. `:first`：第一个文件。
4. `:last`：最后一个文件。
5. `:<number>next`：向后跳多个文件。

## 未保存时怎么切换

如果当前文件有修改，直接执行 `:next` 往往会被阻止。常见处理方式有：

1. `:next!`：放弃当前修改后切换。
2. `:wnext`：先保存，再切换。

## 查看和重设参数列表

1. `:args`：查看当前参数列表。
2. `:args filelist...`：重新设置参数列表。

## 文件间快速跳转

1. `CTRL-^`：在最近两个文件之间来回切换。
2. `` `" ``：跳到该文件上次退出时的大致位置。
3. `` `. ``：跳到最后一次修改位置。
4. `CTRL-O` 和 `CTRL-I`：在跳转历史中前后移动。

## 跨文件标记

1. `m<char>`：小写标记通常只在当前文件内使用。
2. `m<char>` 中如果 `<char>` 是大写字母，则可以做跨文件标记。
3. `` `<char> ``：跳到标记位置。

## 备份与补丁模式

### 备份文件

```vim
:set backup
```

默认备份文件通常会追加 `~` 后缀。也可以进一步配置：

```vim
:set backupext=.bak
:set backupdir=~/
```

### patchmode

```vim
:set patchmode=.orig
```

它适合保留“修改前原始版本”的副本，而不是只保留最近一份备份。

## 跨文件复制与粘贴

同一个 Neovim 会话里，复制内容会进入寄存器，因此可以跨文件粘贴。

例如：

1. `"f3yy`：把 3 行复制到寄存器 `f`。
2. `"fp`：把寄存器 `f` 的内容粘贴出来。

这种方式比来回切文件再重新选中更稳定。

## 另存为

```vim
:saveas newname
```

执行后，当前缓冲区后续的 `:write` 将写入新文件。

## 使用建议

1. 多文件工作时，先区分“参数列表”“缓冲区”“窗口”三者的角色，不然很容易混乱。
2. 如果只是两个文件来回切换，优先用 `CTRL-^`，效率很高。
3. 如果场景开始偏向并排对照，再继续看 [10.多窗口](./10.多窗口.md)。---
