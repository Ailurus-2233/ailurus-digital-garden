Linux 上很多权限问题、本地服务问题，最后都会回到用户和用户组。与其死记命令，不如先分清楚三个对象：用户、主组、附加组。

## 1. 增加用户

```bash
useradd [选项] 用户名
```

常见选项：

1. `-c`：用户说明。
2. `-d`：家目录。
3. `-g`：主组。
4. `-G`：附加组。
5. `-s`：登录 shell。
6. `-u`：用户 ID。

示例：

```bash
sudo useradd -c "test user" -d /home/test -g users -G sudo -s /bin/bash -u 1002 test
```

创建后通常还需要再设置密码：

```bash
sudo passwd test
```

## 2. 删除用户

```bash
userdel [选项] 用户名
```

常用选项：

1. `-r`：删除用户时同时删除家目录。

## 3. 修改用户

```bash
usermod [选项] 用户名
```

常见选项：

1. `-c`：修改说明。
2. `-d`：修改家目录。
3. `-g`：修改主组。
4. `-G`：修改附加组。
5. `-s`：修改默认 shell。
6. `-u`：修改 UID。
7. `-L`：锁定用户。
8. `-U`：解锁用户。

## 4. 查看用户信息

```bash
id 用户名
```

这个命令在排查服务权限时特别常用，因为它能快速看到 UID、GID 和附加组。

## 5. 修改密码

```bash
passwd 用户名
```

## 6. 常见系统文件

1. `/etc/passwd`：用户基本信息。
2. `/etc/shadow`：密码和密码策略相关信息。
3. `/etc/group`：组信息。
4. `/etc/gshadow`：组密码等敏感信息。
5. `/etc/login.defs`：用户与密码策略默认配置。
6. `/etc/default/useradd`：用户创建时的默认参数。

## 7. 使用建议

1. 如果只是想给用户额外权限，优先考虑附加组，不要直接滥用 root。
2. 改完用户或组之后，如果是长期运行的服务，往往还需要重启服务进程才能看到新权限。
3. 如果目录访问异常，除了查用户组，还要结合 [3.文件权限管理](./3.文件权限管理.md) 一起看。
